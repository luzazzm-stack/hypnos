Benchmark results

Latest (14 October 2026): v0.9 ties v0.8 on LoCoMo, 60.5% each, answered by Muse Spark 1.3 and graded by Claude Haiku 5.5. Answered by Claude Opus 5.5 (29 September, graded by Claude Haiku 4.5), v0.8 scores 73% with ~610 tokens of context, ahead of Mem0 (70%) and GBrain (67%). Answered by Muse Spark 1.3 (small free model, graded by Claude Haiku): v0.8 55%, Mem0 51%, GBrain 51%. Earlier tests (own coding sessions, LoCoMo v0.6) follow below.

How each system was set up

  • My architecture v0.6, v0.7 and v0.8: hypnos, the same stored memories (sleep consolidation, Jev decisions, bge-small vectors). v0.7: evidence-first hybrid recall. v0.8: Jev-routed recall: Jev picks the question type, the summary level that answers, and each fact or message that is part of the answer.
  • Mem0: mem0ai 2.2 open source, its own fact extraction (Muse as its LLM), bge-small embeddings, local Qdrant, with spaCy extras; one add per chat session.
  • GBrain: gbrain 0.59, PGLite, hybrid search (keyword + vector + RRF) with bge-small, one page per chat session. Its reranker and LLM query expansion were off, because both need paid APIs.
  • Keyword search: the top 10 raw turns by keyword match.

How the tests were run

  • Answering model: Claude Opus 5.5 (medium effort) for the Opus run (29 September); Muse Spark 1.3 through stock opencode for all the others. Always the same model for every system in a test.
  • Grader: Claude Haiku 5.5 for v0.9 vs v0.8 (14 October); Claude Haiku 4.5 for the LoCoMo runs of 28–29 September.
  • Grading: own-sessions test, Muse Spark against exact quotes; LoCoMo, Claude Haiku (a different model family), with all answers to a question graded side by side and anonymised.
  • LoCoMo (Maharana et al., 2024): 10 long two-person chats, 200 questions, 50 in each of 4 categories; the adversarial category is excluded, as in most published results.
  • Head-to-head runs were split over two laptops on different internet connections and merged; every question is graded with all systems' answers together.
  • Every model call is cached, so each test can be rerun or extended cheaply. Harnesses: benchmark/sessions, benchmark/locomo, benchmark/locomo/compare (run_v07.py, run_v08.py, run_rust.py, run_opus.py, run_v09.py) in the agent-memory-architecture repo.
